Este é um padrão nomeado: tem página permanente porque a ideia precisa poder ser
citada sem citar o post. É o desenho que eu uso para organizar um programa
corporativo de IA, e ele se sustenta há tempo suficiente para eu confiar nele.

Um programa de IA que tenta ser uma coisa só falha de um jeito previsível: vira
plataforma sem adoção, ou vira coleção de pilotos sem plataforma. As quatro frentes
existem para que as tensões entre esses modos de falha fiquem explícitas, e para que
cada uma tenha dono.

## 1. Governança e cultura

Define o que pode, o que não pode, e quem decide quando é caso novo. Inclui o
comitê, os critérios de aprovação, o registro de casos de uso e o trabalho contínuo
de formação.

O erro comum é tratar governança como freio. Ela é o oposto: é o que permite dizer
sim rápido, porque o critério já está escrito. Sem ela, cada decisão vira uma
negociação do zero, e o custo disso aparece como lentidão, não como risco.

## 2. Plataforma

A infraestrutura compartilhada — acesso a modelos, dados, observabilidade, controle
de custo, padrões de integração. É a frente que ninguém vê quando funciona.

O critério de sucesso é negativo: quantas equipes **não** precisaram resolver o
mesmo problema de novo. Se cada aplicação está montando sua própria autenticação e
seu próprio log, não existe plataforma — existe um repositório com nome de
plataforma.

## 3. Aplicações

Machine learning e agentes em produção, resolvendo decisões específicas. É a frente
que gera valor visível, e por isso a que sofre mais pressão para pular as outras
três.

Cada aplicação precisa responder o teste de três frases: que decisão muda, como ela
é tomada hoje, e o que precisa mudar para dizermos que funcionou.

## 4. Estratégia e inovação

Olha para fora e para frente: o que está maduro o suficiente para entrar, o que
ainda não está, e o que a organização vai precisar em dois anos. Também é a frente
que mata iniciativa — dizer não é produto dela.

## Por que quatro, e não três ou cinco

As frentes não são departamentos; são tensões. Governança puxa para o controle,
aplicações puxam para a velocidade, plataforma puxa para o padrão, estratégia puxa
para o novo. Um programa saudável é aquele em que as quatro discutem.

Quando eu tentei operar com três, uma das tensões sumiu do organograma e voltou como
conflito pessoal. Com cinco, a quinta nunca tinha pauta própria.
